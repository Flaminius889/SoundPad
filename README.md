# Soundpad copy without microphone playback

This is a copy of the Soundpad application with the low-level audio-to-microphone path removed.

The Settings dialog still lists recording devices and saves the selected microphone. Playback is routed through the selected output device; choosing a microphone does not inject audio into it.

The CMake project and installer scripts are retained. Generated build and distribution files, the native APO, its bridge, and APO-specific setup scripts are excluded.
